# wer9loc — تغيير موقع الـ iPhone بالكامل (كل التطبيقات)

> أداة تغيّر موقع الـ **GPS للجهاز كامل** — كل التطبيقات ترى الموقع الجديد، ليس
> المتصفح فقط. تعمل عبر **آلية Apple الرسمية نفسها** التي يستخدمها Xcode
> (Simulate Location)، من خلال مكتبة `pymobiledevice3` مفتوحة المصدر.

---

## ⚠️ الحقيقة الكاملة — اقرأها كلها قبل أن تبدأ

طلبت "برنامج على iOS يغيّر موقع الجوال بالكامل، دقيق، بدون ثغرات، ويبقى حتى
أوقفه". إليك ما هو **ممكن فعلًا** وما هو **غير ممكن**، بصدق:

1. **لا يمكن لأي تطبيق مستقل على iOS أن يغيّر موقع الجهاز كامل.** نظام iOS
   (الـ sandbox) يمنع ذلك تمامًا. لتغيير موقع كل التطبيقات تحتاج **واحدة** من:
   - **جهاز كمبيوتر + كابل USB** يشغّل أداة تطوير (هذا ما تبنيه هذه الأداة —
     الطريقة النظيفة والرسمية). ✅
   - أو **جلبريك (Jailbreak)** وتثبيت أداة نظام مثل تعديلات CoreLocation. هذا
     يلغي الضمان، خطر أمنيًا، لا يتوفر لكل الإصدارات، وقابل للكشف. ❌ لا أبنيه.
2. **"بدون أي ثغرة / غير قابل للكشف" غير واقعي.** التطبيقات الجدية تقارن
   الموقع مع **عنوان IP + شبكات WiFi + المستشعرات**، وتكتشف تفعيل **Developer
   Mode**. لتقليل التعارض: استخدم **VPN** في نفس منطقة الموقع المختار. لا أحد
   يستطيع أن يعدك بتخفٍّ 100%.
3. **"يبقى حتى أوقفه":** الموقع يبقى مثبتًا طالما الأداة (وعلى iOS 17+ النفق
   `tunnel`) تعمل على الكمبيوتر. أمر `hold` يثبّته ويعيد تأكيده حتى تضغط
   Ctrl+C فيعود الموقع الحقيقي. هذا أقصى ما يسمح به iOS بدون جلبريك.

هذه أداة **لجهازك أنت** لأغراض التطوير والاختبار والخصوصية.

## المتطلبات

- كمبيوتر: **macOS** (الأسهل) أو **Linux** أو **Windows**.
- **Python 3.9+**.
- كابل USB.
- على الجهاز: **iOS 16 فأقل** (مباشر) أو **iOS 17+** (يحتاج تفعيل نفق + Developer Mode).
- Linux: ثبّت `usbmuxd` (`sudo apt install usbmuxd`). Windows: ثبّت *Apple
  Mobile Device Support* (يأتي مع iTunes). macOS: مدمج.

## التثبيت

```bash
cd ios-device
bash setup.sh          # ينشئ بيئة .venv ويثبّت pymobiledevice3
```

## الاستخدام

كل الأوامر عبر مفسّر البيئة: `./.venv/bin/python wer9loc.py <command>`
(أو فعّل البيئة: `source .venv/bin/activate` ثم `python wer9loc.py …`).

### 1) تأكد من الاتصال
```bash
python wer9loc.py status
```
يعرض الـ UDID وإصدار iOS، ويخبرك إن كنت تحتاج نفقًا (iOS 17+).

### 2) iOS 16 فأقل — مباشرة
```bash
python wer9loc.py set  --lat 48.8584 --lng 2.2945       # برج إيفل
python wer9loc.py set  --place "Times Square, New York" # بالاسم
python wer9loc.py hold --lat 25.2048 --lng 55.2708      # يثبّت حتى Ctrl+C
python wer9loc.py clear                                  # إرجاع الموقع الحقيقي
```

### 3) iOS 17+ — مع النفق
في **نافذة طرفية أولى** (تبقى مفتوحة، تحتاج صلاحية root):
```bash
sudo python wer9loc.py tunnel
```
وفعّل على الجهاز: *Settings → Privacy & Security → Developer Mode*.
ثم في **نافذة ثانية**:
```bash
python wer9loc.py set  --lat 48.8584 --lng 2.2945
python wer9loc.py hold --place "Dubai Mall"
```
> بديل: مرّر عنوان RSD يدويًا بعد `start-tunnel`:
> `python wer9loc.py set --rsd HOST:PORT --lat .. --lng ..`

### 4) محاكاة حركة (مسار)
```bash
# مسار مستقيم بين نقطتين بسرعة 6 م/ث
python wer9loc.py route --from 48.8584,2.2945 --to 48.8606,2.3376 --speed 6
# أو تشغيل ملف GPX جاهز
python wer9loc.py route --gpx mywalk.gpx
```

## الأوامر باختصار

| الأمر | الوظيفة |
|------|---------|
| `status` | عرض الجهاز والوضع (مباشر / نفق). |
| `search "مكان"` | تحويل اسم المكان إلى إحداثيات. |
| `set` | تثبيت موقع ثابت. |
| `hold` | تثبيت الموقع وإعادة تأكيده حتى Ctrl+C ثم الإرجاع. |
| `route` | التحرّك على طول مسار (GPX أو from/to). |
| `clear` | إيقاف المحاكاة وإرجاع الـ GPS الحقيقي. |
| `tunnel` | تشغيل نفق iOS 17+ (بـ sudo). |

## استكشاف الأخطاء

- **لا يظهر الجهاز:** افتح قفل الجهاز، اضغط *Trust*، تأكد من usbmuxd/Apple
  Mobile Device Support، جرّب كابلًا/منفذًا آخر.
- **iOS 17+ يعطي خطأ اتصال:** تأكد أن `sudo … tunnel` يعمل وأن Developer Mode
  مفعّل، ثم أعد المحاولة.
- **الموقع رجع للحقيقي فجأة:** غالبًا توقفت الأداة/النفق — استخدم `hold` وابقِ
  النافذة مفتوحة.

## لماذا هذه الطريقة وليست "تطبيق واحد"؟
لأن iOS ببساطة لا يسمح بغير ذلك. هذه الأداة تعطيك أنظف حل حقيقي وموثوق
(نفس محرّك Xcode)، بدل وعود وهمية بتطبيق "سحري غير قابل للكشف" لا وجود له.
