# wer9loc — تغيير موقع الـ iPhone بالكامل (كل التطبيقات)

> أداة تغيّر موقع GPS **للجهاز كامل** — كل التطبيقات ترى الموقع الجديد، ليس
> المتصفح فقط. تعمل عبر **آلية Apple الرسمية نفسها** (نفس محرّك Xcode
> "Simulate Location") من خلال مكتبة `pymobiledevice3` مفتوحة المصدر.
> **بدون جلبريك.** تحتاج فقط كمبيوتر وكابل USB.

---

## ⚡ التشغيل السريع (ويندوز) — أسهل طريقة

1. **ثبّت المتطلبات على الكمبيوتر مرة واحدة:**
   - **Python 3**: من <https://www.python.org/downloads/> — وعند التثبيت
     ✅ ضع علامة على **"Add python.exe to PATH"**.
   - **iTunes** (أو Apple Mobile Device Support) من موقع Apple — ليتعرّف
     ويندوز على الآيفون.
2. **وصّل الآيفون** بالكابل، افتح قفله، واضغط **"Trust / وثوق"** على الجهاز.
3. **انقر مرتين على `wer9loc.bat`**. أول مرة سيثبّت نفسه تلقائيًا، ثم تفتح
   قائمة بسيطة.
4. من القائمة اختر **1**، اكتب اسم المكان (أو `lat,lng`)، واختر تثبيته حتى توقفه.
5. للإيقاف: اختر **3** (أو أغلق النافذة) فيعود الموقع الحقيقي.

> **iOS 17 أو أحدث فقط:** قبل الخطوة 3، انقر مرتين على **`wer9loc-tunnel.bat`**
> واسمح بصلاحية *Administrator*، واتركه مفتوحًا. وفعّل على الآيفون:
> *Settings → Privacy & Security → Developer Mode*.

## ⚡ التشغيل السريع (macOS / Linux)

```bash
cd ios-device
./run.sh                 # يثبّت نفسه أول مرة، ثم يفتح القائمة
# iOS 17+ في نافذة ثانية:
sudo ./run.sh tunnel
```
Linux: ثبّت الخدمة أولًا `sudo apt install usbmuxd`. macOS: مدمجة.

---

## ⚠️ الحقيقة الكاملة (مهمة)

- **بدون جلبريك، لكن يجب أن يبقى الآيفون موصولًا بالكمبيوتر** طالما تريد الموقع
  مثبتًا. بمجرد فصل الكابل أو إغلاق الأداة، يعود الموقع الحقيقي تدريجيًا. هذا
  قيد من iOS، لا يمكن تجاوزه بدون جلبريك.
- **لا يوجد "غير قابل للكشف 100%".** التطبيقات الجدية تقارن الموقع مع **IP +
  شبكات WiFi + المستشعرات**، وتكتشف تفعيل Developer Mode. لتقليل التعارض
  استخدم **VPN** في نفس منطقة الموقع المختار.
- هذه أداة **لجهازك أنت** لأغراض التطوير والاختبار والخصوصية.

## الاستخدام المتقدم (سطر الأوامر)

بدل القائمة، تقدر تنادي الأوامر مباشرة:

```bash
# ويندوز:  .venv\Scripts\python wer9loc.py <command>
# ماك/لينكس: ./run.sh <command>

status                                   # عرض الجهاز والوضع
search "Eiffel Tower"                     # اسم مكان -> إحداثيات
set   --lat 48.8584 --lng 2.2945          # تثبيت موقع
set   --place "Times Square, New York"    # بالاسم
hold  --lat 25.2048 --lng 55.2708         # يثبّت حتى Ctrl+C ثم يرجّع الحقيقي
route --from 48.8584,2.2945 --to 48.8606,2.3376 --speed 6   # حركة
route --gpx mywalk.gpx                     # تشغيل مسار GPX
clear                                      # إرجاع الموقع الحقيقي
tunnel                                     # (iOS 17+) تشغيل النفق، بـ sudo
```

| الأمر | الوظيفة |
|------|---------|
| `status` | عرض الجهاز والوضع (مباشر / نفق). |
| `search` | تحويل اسم المكان إلى إحداثيات. |
| `set` | تثبيت موقع ثابت. |
| `hold` | تثبيت الموقع وإعادة تأكيده حتى Ctrl+C ثم الإرجاع. |
| `route` | التحرّك على طول مسار. |
| `clear` | إيقاف المحاكاة وإرجاع الـ GPS الحقيقي. |
| `tunnel` | تشغيل نفق iOS 17+ (بصلاحية إدارية). |

## الملفات

| الملف | الدور |
|------|------|
| `wer9loc.py` | المحرّك الرئيسي (قائمة تفاعلية + أوامر). |
| `wer9loc.bat` | مشغّل ويندوز بنقرة (إعداد + قائمة). |
| `wer9loc-tunnel.bat` | نفق iOS 17+ لويندوز (يطلب صلاحية إدارية). |
| `run.sh` | مشغّل macOS/Linux. |
| `setup.sh` | إعداد البيئة (venv + التثبيت). |
| `requirements.txt` | الاعتمادية: `pymobiledevice3`. |

## استكشاف الأخطاء

- **لا يظهر الجهاز:** افتح قفل الآيفون، اضغط *Trust*، تأكد من تثبيت iTunes
  (ويندوز) أو usbmuxd (لينكس)، جرّب كابلًا/منفذًا آخر (كابل أصلي يفضّل).
- **iOS 17+ يعطي خطأ اتصال (RSD/tunnel):** تأكد أن `wer9loc-tunnel.bat`
  (أو `sudo ./run.sh tunnel`) يعمل، وأن Developer Mode مفعّل، ثم أعد المحاولة.
- **الموقع رجع للحقيقي فجأة:** توقفت الأداة/النفق أو فُصل الكابل — استخدم
  الخيار الذي يبقيه مثبتًا وابقِ النافذة/الكابل موصولًا.
- **"pymobiledevice3 not found":** أعد تشغيل `wer9loc.bat` (يعيد التثبيت)،
  أو ثبّت يدويًا: `pip install -r requirements.txt`.
