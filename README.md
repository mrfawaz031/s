# GeoSet — Location Override (متصفحك أنت)

> **بالعربي:** إضافة متصفح تجعل مواقع الويب ترى موقعك الجغرافي في المكان الذي
> تختاره من الخريطة، بدل موقعك الحقيقي. مخصّصة لـ **تطوير واختبار** الميزات
> المعتمدة على الموقع و**حماية الخصوصية** على جهازك أنت.
>
> **In English:** A browser extension that makes websites read the location you
> pick on a map instead of your real one — for **web development, testing, and
> privacy** on your own device.

---

## ⚠️ اقرأ هذا أولاً — الحقيقة الكاملة (Read this first)

- **لا يوجد تزييف موقع "غير قابل للكشف 100%".** الأنظمة المتقدمة (البنوك،
  تطبيقات التوصيل، الألعاب، أنظمة كشف الاحتيال) تقارن عدة إشارات معًا:
  **GPS + عنوان IP + شبكات WiFi المحيطة + أبراج الاتصال + المستشعرات**. هذه
  الأداة تعدّل واجهة الموقع في المتصفح فقط؛ إذا كان موقعك (IP) في بلد وأخبرت
  الموقع أنك في بلد آخر، فقد تُكشف بمقارنة الإشارتين.
- لجعل عنوان الـ IP متوافقًا مع الموقع المختار، تحتاج **VPN** في نفس المنطقة.
- **هذه الأداة لجهازك ومتصفحك أنت** — للتطوير والاختبار والخصوصية. لا
  تستخدمها للاحتيال أو تجاوز ضوابط الأمان لدى طرف آخر.
- تعمل على **مواقع الويب** (طبقة `navigator.geolocation`). لا تغيّر موقع
  التطبيقات الأصلية على أندرويد/آيفون (لذلك انظر قسم الجوال أدناه).

## المزايا (Features)

- 🗺️ اختيار الموقع من خريطة تفاعلية (Leaflet + OpenStreetMap) — بالنقر أو
  بسحب المؤشّر.
- 🔎 بحث بالاسم (مدينة/عنوان/معلم) عبر OpenStreetMap Nominatim.
- 🎯 التحكم بدقة الموقع (accuracy) بالمتر.
- 🌊 **انجراف واقعي**: كل قراءة تتحرك قليلًا حول النقطة (مثل GPS الحقيقي) بدل
  إرجاع نفس الأرقام حرفيًا.
- ⚡ مفتاح تشغيل/إيقاف فوري + حفظ تلقائي + تحديث حيّ لكل التبويبات.
- 🔒 مكتفية ذاتيًا: لا كود خارجي، متوافقة مع Manifest V3.

## التثبيت (Install) — Chrome / Edge / Brave

1. افتح `chrome://extensions` (أو `edge://extensions`).
2. فعّل **Developer mode** (وضع المطوّر) من الأعلى.
3. اضغط **Load unpacked** واختر مجلد **`extension`** من هذا المستودع.
4. ستظهر أيقونة الإضافة في الشريط. ثبّتها (pin) لتصل إليها بسهولة.

> ملاحظة: تحتاج المتصفح إصدار حديث (Chrome/Edge 111+) لأن الإضافة تستخدم
> `world: "MAIN"` في content scripts.

## الاستخدام (Usage) — خلال أقل من دقيقة

1. اضغط أيقونة **GeoSet**.
2. ابحث عن مكان أو انقر على الخريطة أو أدخل الإحداثيات يدويًا.
3. اضبط **Accuracy** إن أردت.
4. فعّل المفتاح العلوي (يصبح **Override is ON**).
5. **أعد تحميل** التبويب المستهدف — الآن يرى الموقع المختار.
6. للتأكد: افتح `extension/test.html` واضغط الأزرار لرؤية القراءة.

## الإيقاف

أطفئ المفتاح العلوي (Override is OFF) وأعد تحميل الصفحة — يعود موقعك الحقيقي.

---

## الجوال (Mobile) — الطريقة الرسمية والأنظف

هذه الإضافة للمتصفح على الحاسب. لتغيير موقع **الجهاز كله** استخدم الأدوات
المدمجة والمشروعة:

- **Android:** فعّل *Developer options* → اختر تطبيق *mock location* → استخدم
  تطبيق مثل الأدوات المخصّصة للمطوّرين. أو عبر ADB:
  ```
  adb shell appops set <package> android:mock_location allow
  ```
- **iOS:** عبر Xcode → *Simulate Location*، أو ملف `.gpx` في مشروع تطوير.
- **متصفح كروم على الحاسب** (بديل بدون إضافة): DevTools → قائمة `⋮` → *More
  tools* → **Sensors** → *Location* → *Other…* وأدخل الإحداثيات.

## كيف تعمل (How it works)

| الملف | الدور |
|------|------|
| `src/inject.js` | يعمل في **MAIN world** ويستبدل `getCurrentPosition` / `watchPosition` / `clearWatch` (و`permissions.query` للموقع) بقيَم الموقع المختار مع انجراف واقعي. |
| `src/content.js` | يعمل في **ISOLATED world**، يقرأ الإعداد من `chrome.storage` ويرسله إلى `inject.js` عبر `postMessage`، ويبثّ التحديثات الحيّة. |
| `src/popup.*` | لوحة التحكم: الخريطة، البحث، الإحداثيات، الدقة، مفتاح التشغيل. |
| `vendor/leaflet/*` | مكتبة الخريطة (محليًا، بدون CDN). |

## القيود المعروفة (Limitations)

- لا تؤثر على موقع IP — استخدم VPN مطابقًا للموقع لتفادي تعارض الإشارات.
- بعض التطبيقات تستخدم مصادر موقع أصلية (native) لا تمرّ عبر واجهة المتصفح.
- Firefox يدعم `world:"MAIN"` في إصدارات حديثة فقط؛ الأساس هنا Chromium.
