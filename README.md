# wer9store — Location Override

> **بالعربي:** أداة احترافية تجعل مواقع الويب ترى موقعك الجغرافي في المكان الذي
> تختاره من الخريطة بدل موقعك الحقيقي — مع **تثبيت الموقع حتى الإيقاف**، مواقع
> محفوظة، ومحاكاة حركة واقعية. مخصّصة لـ **تطوير واختبار** الميزات المعتمدة على
> الموقع و**حماية الخصوصية** على جهازك أنت. تعمل على الحاسب (Chrome/Edge/Brave)
> وعلى **iPhone/iPad** عبر Safari Web Extension.

---

## ⚠️ الحقيقة الكاملة (اقرأها قبل الاستخدام)

- **لا يوجد تزييف موقع "غير قابل للكشف 100%".** الأنظمة المتقدمة تقارن عدة
  إشارات معًا: **GPS + عنوان IP + شبكات WiFi + المستشعرات**. هذه الأداة تعدّل
  طبقة الموقع في المتصفح فقط.
- إذا كان الـ IP في بلد وأخبرت الموقع أنك في بلد آخر → يمكن كشف التعارض.
  **الحل:** استخدم **VPN** في نفس منطقة الموقع المختار.
- تعمل على **مواقع الويب**، لا على التطبيقات الأصلية للجوال.
- **لجهازك ومتصفحك أنت** — للتطوير والاختبار والخصوصية.

## ✨ المزايا

| الميزة | الوصف |
|--------|-------|
| 🗺️ اختيار من الخريطة | انقر أو اسحب المؤشّر، أو ابحث بالاسم (Nominatim). |
| 📌 **تثبيت الموقع (Lock)** | يبقى الموقع ثابتًا **حتى تطفئ المفتاح** — عبر إعادة تحميل الصفحات وإعادة تشغيل المتصفح. |
| 🚶 **محاكاة حركة** | سرعة (كم/س) + اتجاه، وتُرجع `heading`/`speed` حقيقية للتطبيقات التي تتتبع المسار. |
| 🎯 دقة قابلة للضبط | تحديد `accuracy` بالمتر + انجراف واقعي لكل قراءة. |
| ⭐ مواقع محفوظة | احفظ أماكنك المفضّلة وطبّقها بضغطة، مع حذف. |
| ⬇️⬆️ تصدير/استيراد | انسخ إعداداتك ومواقعك كملف JSON. |
| 🔒 مكتفية ذاتيًا | Leaflet محليًا، بدون كود خارجي — متوافقة مع Manifest V3. |
| 🍎 دعم iOS | تُبنى كـ Safari Web Extension (انظر `ios/BUILD-SAFARI-iOS.md`). |

## 🖥️ التثبيت والتشغيل — Chrome / Edge / Brave

1. افتح `chrome://extensions` (أو `edge://extensions`).
2. فعّل **Developer mode** من الأعلى يمين.
3. اضغط **Load unpacked** واختر مجلد **`extension`**.
4. ثبّت الأيقونة (pin) في الشريط.

### طريقة الاستخدام (خطوة بخطوة)
1. اضغط أيقونة **wer9store**.
2. **اختر الموقع**: اكتب في مربّع البحث، أو انقر على الخريطة، أو أدخل الإحداثيات.
3. (اختياري) اضبط **Accuracy**، أو فعّل **Motion simulation** (سرعة + اتجاه).
4. (اختياري) اكتب اسمًا واضغط **Save** لحفظ المكان في المفضّلة.
5. **فعّل المفتاح العلوي** → يظهر شريط أخضر: **LOCKED — active until you turn it OFF**.
6. **أعد تحميل** التبويب المستهدف. الآن يرى الموقع المختار، ويبقى مثبتًا حتى تطفئ المفتاح.
7. للتأكد: افتح `extension/test.html`.

### الإيقاف
أطفئ المفتاح العلوي (يعود إلى **Override OFF**) وأعد تحميل الصفحة → يعود موقعك الحقيقي.

## 🍎 التشغيل على iPhone / iPad

الطريقة الرسمية الوحيدة هي بناء الإضافة كتطبيق Safari عبر **Xcode على Mac**.
الدليل الكامل خطوة بخطوة في: **[`ios/BUILD-SAFARI-iOS.md`](ios/BUILD-SAFARI-iOS.md)**.

باختصار:
```bash
bash scripts/build-safari.sh            # يحوّل extension/ إلى مشروع Xcode
open ios/build/wer9store/wer9store.xcodeproj
```
ثم: وقّع المشروع بحسابك → شغّله على الـ iPhone → فعّل الإضافة من
*Settings → Safari → Extensions*.

> تغيير موقع **الجهاز كله** على iOS (لا المتصفح فقط) يتطلب Xcode *Simulate
> Location* أو جلبريك، وكلاهما مؤقّت/قابل للكشف — مشروح في نفس الدليل.

## 🔧 كيف تعمل

| الملف | الدور |
|------|------|
| `extension/src/inject.js` | MAIN world: يستبدل `getCurrentPosition`/`watchPosition`/`clearWatch` و`permissions.query`، مع انجراف واقعي ومحاكاة حركة (heading/speed). |
| `extension/src/content.js` | ISOLATED world: يقرأ الإعداد من `chrome.storage` ويرسله إلى `inject.js` عبر `postMessage`، ويبثّ التحديثات الحيّة. |
| `extension/src/popup.*` | لوحة التحكم: الخريطة، البحث، الحركة، المواقع المحفوظة، التصدير/الاستيراد. |
| `extension/vendor/leaflet/*` | مكتبة الخريطة محليًا (بدون CDN). |
| `ios/` + `scripts/build-safari.sh` | تحويل الإضافة إلى تطبيق Safari لـ iOS. |

## القيود المعروفة
- لا تؤثر على موقع IP — استخدم VPN مطابقًا.
- بعض التطبيقات تستخدم مصادر موقع أصلية (native) لا تمرّ عبر واجهة المتصفح.
- Firefox/Safari يدعمان `world:"MAIN"` في إصدارات حديثة فقط؛ الأساس Chromium.
